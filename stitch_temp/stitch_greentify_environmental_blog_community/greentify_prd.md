# Greentify Project Overview

## About
Platform blog dan komunitas lingkungan untuk meningkatkan kesadaran dan tindakan positif terhadap pelestarian alam.

## Features (MVP)
- User Authentication (Login/Register/Logout)
- Blog Posts — 4 Kategori Lingkungan (Limbah, Konservasi, Penghijauan, Hutan)
- Contact Form
- Responsive Design
- Modern UI with Tailwind CSS

## Blog Categories
1. **Limbah**: Pengurangan Limbah Plastik
2. **Konservasi**: Konservasi Air & Sumber Daya
3. **Penghijauan**: Penghijauan Kota & Perubahan Iklim
4. **Hutan**: Perlindungan Hutan Hujan & Keanekaragaman

## Design Direction
- Nature-inspired (Forest greens, earth tones)
- Modern editorial typography
- Clean, organic layouts
